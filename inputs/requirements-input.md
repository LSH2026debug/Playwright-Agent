# 星宫需求说明

目标站点是 星宫，一个智能体平台。

约束：

- 只考虑 Chromium
- 优先覆盖主流程与高风险回归流程
- 生成的中间产物必须可读、可审计、可由人工编辑

1. 首页

作为功能跳转的入口，支持四个按键，通过点击跳转到不同页面。

目前开放了All-In-One和知识库模块。

2. All-In-One
2.1 聊天页面

模型与搜索：支持模型切换、联网搜索功能及搜索引擎辅助。

会话管理：包括提问、清空、历史记录等操作。

界面与输出设置：可调整并行调用的模型数量，统一输入多个Bot，支持流式输出。

输入与发送：快捷发送方式切换（Enter或Shift+Enter），支持上传单个附件。

2.2 参数设置

支持选择模型，输入提示词标题和内容，调用已有提示词。

提供多个可调参数，用于控制模型输出的细节。

3. 知识库
3.1 私域检索

用户可创建会话、切换模型、选择数据库并进行检索。

支持RAG和KAG两种增强生成技术。

3.2 知识库管理

可以搜索和新建知识库。

已建知识库可编辑，支持批量删除操作。

3.3 文件管理

支持文件上传、训练与更新。

文件属性可作为搜索条件，支持批量操作。

3.4 问答历史

显示提问、回答、准确性评价及时间等信息，支持回顾历史内容。

4. 授权管理

根据角色名称和创建人进行快速查找授权条目。

提供详细的授权管理视图。

5. Agent（智能体）
5.1 AI应用区

支持搜索智能体，展示智能体功能概览。

5.2 个人空间

用户可以查看和管理自己发布的所有智能体。

5.3 智能体创建

用户可自由配置智能体结构，选择工作空间、工作库、知识库及工具。

支持新建和管理智能体。

5.4 Agent发布申请与审批

完成智能体创建后，用户可提交发布申请进行审批。

5.5 Agent管理

支持已发布智能体的启停管理。

6. 模型管理

包含模板管理、资源管理和授权记录。

支持按类型和场景搜索模型，并提供模型编辑功能。

7. MCP服务
7.1 MCP市场

用户可查看和搜索已发布的服务，并申请授权。

7.2 个人中心

展示已添加的MCP服务及其状态，支持启用、删除、申请授权等操作。

7.3 授权审批

处理用户服务申请的审批，包括待办、已通过和已驳回状态。

8. 系统管理
8.1 用户管理

集中维护平台用户信息，支持按部门维度查看、修改、删除用户。

8.2 角色管理

集中管理平台角色信息，支持批量操作、权限分配等功能。

8.3 菜单管理

管理平台菜单信息，支持菜单的增删改查。

8.4 公司管理

管理公司部门信息，支持部门的增删改查。

8.5 字典管理

管理字典信息，支持字典的增删改查。

8.6 日志管理

管理平台操作日志和登录日志，支持日志的搜索、删除和导出。

此为智能体平台的主要功能点概述。如果需要更详细的需求描述或其他相关模块的扩展，请告知！

1. 首页
1.1 功能

首页作为平台的入口，提供四个主要按键：

All-In-One模块：用户可跳转至All-In-One功能。

知识库模块：用户可跳转至知识库管理页面。

其他功能按钮（可能会根据系统版本进行扩展）。

1.2 功能需求

用户可通过点击按钮跳转到对应页面，便捷地进行功能选择。

2. All-In-One
2.1 聊天页面
主要功能：

模型与搜索：

支持通过下拉列表选择不同的模型进行对话。

支持联网搜索功能，选择搜索引擎辅助对话，增强对话的灵活性与准确性。

会话管理：

提供“提问”“清空”“历史”操作，方便用户与模型进行互动。

用户可以单独与某个模型交互，清除对话历史或查看历史记录。

界面与输出设置：

允许用户调整并行调用的模型数量。

可以统一输入多个Bot进行交互。

支持流式输出功能，逐步生成回答以提高用户体验。

输入与发送：

支持快捷发送方式（Enter键或Shift+Enter键）。

支持上传单个附件，也可直接将输入内容发送至所有模型。

用户需求：

用户希望通过界面直观控制聊天过程，包括对模型的选择、输入方式的调整以及聊天内容的管理。

2.2 参数设置
主要功能：

提示词配置：

支持选择模型，并在下方输入提示词标题与内容。

用户可在“我的”或“社区”中查找并使用已有的提示词组，方便调用和使用。

参数调节：

提供多个可调参数，以便控制模型输出的细节和风格。

用户需求：

用户可以根据自己的需求灵活调整提示词和参数设置，确保模型输出符合预期。

3. 知识库
3.1 私域检索
主要功能：

会话创建与内容更换：

用户可从首页或侧边栏进入知识库模块，创建新会话并切换推荐内容。

历史记录检索：

系统记录历史问答，并提供搜索功能帮助用户快速定位所需信息。

增强生成技术：

支持RAG（Retriever-Augmented Generation）和KAG（Knowledge-Augmented Generation）两种增强生成技术，以增强对话生成的质量和深度。

用户需求：

用户期望系统能支持快速检索历史记录，并且能够使用增强生成技术提高对话的智能性和准确性。

3.2 知识库管理
主要功能：

知识库搜索与创建：

用户可通过搜索功能快速定位现有的知识库。

支持新建知识库，为不同场景生成新的知识库，并设置名称和描述。

知识库编辑：

已建知识库支持编辑，用户可添加更多文件内容，并通过批量操作进行管理。

用户需求：

用户期望能够灵活地创建、管理和编辑知识库，并通过有效的搜索和编辑功能提高工作效率。

3.3 文件管理
主要功能：

文件上传与管理：

支持文件上传、训练与更新，用户可上传多种格式的文件。

用户可以将同一个文件同时加入多个知识库。

批量操作与高效筛选：

提供批量选择文件进行训练与更新，提升操作效率。

文件展示包括名称、格式、训练状态、大小、页数、tokens数量等信息，支持根据这些信息进行筛选与搜索。

用户需求：

用户希望文件管理功能支持批量操作，能够高效管理和更新文件。

3.4 问答历史
主要功能：

历史记录显示与查询：

系统记录用户提问、回答、准确性评价以及时间等信息。

支持用户通过查询快速定位特定记录，查看完整问答内容。

用户需求：

用户需要清晰地查看和回顾历史问答，并能够根据各种条件进行快速筛选。

4. 授权管理
主要功能：

授权条目管理：

用户可根据角色名称和创建人快速定位授权条目。

提供详细的授权管理界面，支持查看授权详情和权限分配。

用户需求：

用户需要高效的授权管理功能，能够快速查看并调整不同角色的权限。

5. Agent（智能体）
5.1 AI应用区
主要功能：

智能体搜索与浏览：

提供智能体搜索功能，展示智能体功能概览，帮助用户快速定位所需智能体。

用户需求：

用户希望能够方便地搜索和查看已发布的智能体，并进行快速应用。

5.2 个人空间
主要功能：

已发布智能体管理：

用户可查看和管理自己发布的所有智能体，包括历史记录、更新等操作。

用户需求：

用户期望个人空间能够提供方便的智能体管理功能。

5.3 智能体创建
主要功能：

创建与配置智能体：

用户可以根据需求自由配置智能体结构，选择工作空间、工作库、知识库以及工具。

提供标签搜索、工作库切换等功能，支持添加插件。

用户需求：

用户期望创建智能体时，能够自由配置其结构和所需工具，以满足不同的应用场景。

5.4 Agent发布申请与审批
主要功能：

发布申请流程：

完成智能体创建后，用户可以提交发布申请，经过审批流程后完成发布。

管理员可以查看并审批用户提交的发布申请。

用户需求：

用户需要简化发布申请流程，并能够方便地提交与跟踪审批状态。

5.5 Agent管理
主要功能：

智能体启停控制：

用户可管理已发布的智能体，通过启停控制实现统一维护。

用户需求：

用户期望能够方便地启用和停止智能体，进行灵活管理。

6. 模型管理
主要功能：

模型模板与资源管理：

模型管理模块支持模板查看、编辑、加密信息维护等功能。

支持根据场景和类型搜索模型，便于模型资源的管理。

用户需求：

用户需要全面的模型管理功能，包括模型的搜索、编辑和加密等操作。

7. MCP服务
7.1 MCP市场
主要功能：

查看和申请MCP服务：

用户可以查看已发布的MCP服务和预设组合，并申请授权。

用户需求：

用户希望能够方便地浏览和申请使用MCP服务。

7.2 个人中心
主要功能：

MCP服务管理：

个人中心展示已添加的MCP服务及其状态，用户可以对其进行启用、删除、申请授权等操作。

用户需求：

用户期望通过个人中心集中管理所有MCP服务。

8. 系统管理
8.1 用户管理
主要功能：

集中管理用户信息：

用户管理模块支持按部门维度进行组织，能够高效管理用户信息，包括添加、修改、删除操作。

用户需求：

用户需要一个简洁、高效的用户管理界面，便于组织和管理平台用户。

8.2 角色管理
主要功能：

角色信息维护：

角色管理模块支持维护角色信息，包括角色编号、名称、权限、显示顺序等。

用户需求：

用户希望角色管理功能能够方便维护角色和权限，支持批量修改和分配权限。

8.3 菜单管理
主要功能：

菜单信息管理：

支持菜单的增删改查，并提供对应的操作权限设置。

用户需求：

用户需要方便的菜单管理功能，以实现平台界面的灵活调整。
