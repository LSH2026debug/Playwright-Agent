## 背景故事

在尝试使用 Playwright-Agent 进行站点探索时，我遇到了一系列阻碍项目正常运行的问题：

1. **致命的 `__name is not defined` 错误** - 当我点击"开始探索"时，后端直接报错 `locator.evaluateAll: ReferenceError: __name is not defined`，导致整个站点探索功能完全不可用。经过调查发现，这是 TypeScript 编译器在编译时为保留函数名注入的辅助函数，但在 Playwright 的浏览器端执行环境中并不存在。

2. **配置加载失败** - 从非项目根目录启动时，`.env` 文件加载失败，因为代码使用了 `process.cwd()` 来获取当前工作目录，这在不同的启动方式下是不稳定的。

3. **端口冲突** - 开发过程中频繁遇到端口被占用的情况，每次都需要手动查找并杀死占用进程，严重影响开发效率。

4. **代码维护困难** - 在修复上述问题的过程中，发现 `siteExploreService.ts` 中存在大量重复的代码（同一个函数以不同形式定义了4次以上），这使得维护变得异常困难。

5. **缺乏错误处理** - 前端没有任何错误边界，一旦某个组件出错整个应用就白屏；后端也没有日志记录，调试问题时只能靠 `console.log`。

这个 PR 解决了上述所有问题，让项目从"无法运行"变成了"稳定可用"。

## 修复内容

### 1. 修复 `.env` 文件加载路径
**文件**: `backend/src/config.ts`

**问题**: `process.cwd()` 不可靠，从非项目根目录启动时无法加载配置

**修复**: 改用 `import.meta.url` 获取当前文件路径

```typescript
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const envPath = path.resolve(__dirname, '..', '..', '.env');
dotenv.config({ path: envPath });
```

---

### 2. 修复 `__name is not defined` 错误
**文件**: 
- `backend/src/services/siteExploreService.ts`
- 新增 `backend/src/services/selectorBuilder.ts`

**问题**: TypeScript 编译器添加 `__name` 辅助函数，浏览器端执行时未定义

**解决方案**:
- 创建独立的 `selectorBuilder.ts` 模块
- 将浏览器端代码改为字符串形式传递，使用纯 ES5 JavaScript
- 消除代码重复（减少约150行代码）

```typescript
// 修复前 - 会报错
const raw = await page.locator(selector).evaluateAll((elements) => {
  function buildBestSelector(el: Element): string { ... }
});

// 修复后 - 正常工作
const buildBestSelectorFn = `(function(el) {
  if (el.id) return '#' + el.id;
  // ... ES5 代码
})`;

const raw = await page.locator(selector).evaluateAll((elements, params) => {
  const buildSel = new Function('return ' + params.buildSelectorSrc)();
}, { buildSelectorSrc: buildBestSelectorFn });
```

### 3. 添加端口自动检测
**文件**: `backend/src/index.ts`

**问题**: 端口被占用时服务无法启动

**修复**: 自动检测并切换到可用端口

```typescript
async function isPortInUse(port: number): Promise<boolean> { ... }
async function findAvailablePort(startPort: number): Promise<number> { ... }

if (await isPortInUse(port)) {
  port = await findAvailablePort(port);
}
```
